# `/improvements`

## 目的

analysis_runsから生成された改善提案を一覧表示し、詳細確認へ送る。

## 現在UIに表示される主な内容

- Page header
  - Improvements
  - Review generated improvements and risks.
- Improvement cards
  - title/summary
  - score
  - risk
  - review warnings
  - View detail
- Risk/review message
  - `No exaggerated claims, brand risks, or dangerous changes were detected.`

## 主なユーザー操作

- View detail
- Sidebar navigation

## Empty State

```text
No improvements
Run analysis to generate improvements.
```
