# `/ads/new`

## 目的

X広告を手動登録するフォーム画面。

## 現在UIに表示される主な内容

- Form fields
  - project
  - name
  - campaign name
  - ad group name
  - headline
  - body
  - CTA
  - destination URL
  - image/video URL
  - impressions
  - clicks
  - conversions
  - spend
  - status
- Save / submit button
- Back/navigation controls

## 主なユーザー操作

- 広告情報入力
- 保存
- 一覧へ戻る

## Empty State

- projectがない場合、project選択が空になる可能性がある。
- validation不足時は保存失敗または入力エラー。
