# `/campaigns`

> **履歴UI資料:** このページ文書は初期UI監査時点の記録です。現在の画面・接続状態は [`../adflow-ai-current-state.md`](../adflow-ai-current-state.md) を参照してください。


## 目的

登録済み広告をキャンペーン名で集計し、キャンペーン単位の概要と指標を表示する。

## 現在UIに表示される主な内容

- Page header
  - Campaigns
  - Campaign overview from registered ads.
- Search input
  - Search campaigns
- Campaign metric cards
- Campaign table/list
  - Campaign
  - Spend
  - Clicks
  - CTR
  - Status
  - conversionsなどの指標
- AI detected problems / analysis suggestions系の表示

## 主なユーザー操作

- Search campaigns
- Campaign detailへ移動
- Sidebar navigation

## Empty State

```text
No campaigns
Connect an ad source or run analysis to populate campaigns.
No analysis suggestions yet.
```
