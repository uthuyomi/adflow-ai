# `/ads`

## 目的

X広告を一覧表示し、新規登録、編集、削除へ進める。

## 現在UIに表示される主な内容

- Page header
  - `X Ads`
  - `Register X ads manually and keep every create, update, and delete in history.`
  - Button: `New ad`
- Table
  - Name
  - Headline
  - Destination
  - Spend
  - Status
  - Actions
- Row actions
  - Edit ad
  - Delete ad
- Delete confirmation
  - `The ad will be removed, but the delete history remains available.`
  - Delete
  - Cancel

## 主なユーザー操作

- New ad
- Edit ad
- Delete ad
- Confirm delete
- Cancel delete

## Empty State

```text
No X ads
Register an ad manually to start pair-based analysis.
```

## メッセージ

```text
Ad deleted.
Delete failed.
Deleting...
```
