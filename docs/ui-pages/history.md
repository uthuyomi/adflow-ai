# `/history`

## 目的

作成、更新、削除、AI decisionなどの変更履歴を一覧表示する。

## 現在UIに表示される主な内容

- Page header
  - History
  - 変更履歴説明
- History list/table
  - Entity
  - Action
  - Summary
  - Reason
  - Created

## 主なユーザー操作

- 履歴確認
- Sidebar navigation

## Empty State

```text
No history
Create, update, and delete events will appear here.
```
