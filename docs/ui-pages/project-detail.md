# `/projects/[projectId]`

> **履歴UI資料:** このページ文書は初期UI監査時点の記録です。現在の画面・接続状態は [`../adflow-ai-current-state.md`](../adflow-ai-current-state.md) を参照してください。


## 目的

単一プロジェクトの広告、LP、ペア、履歴、分析runを確認する詳細画面。

## 現在UIに表示される主な内容

- Project title
- Project description
- Project metadata
- 関連データの概要
  - ads
  - landing pages
  - ad LP pairs
  - analysis/history context
- 詳細カードまたはリスト

## 主なユーザー操作

- 関連エンティティの確認
- Ads / LPs / Pairs などへ移動
- Sidebar navigation

## Empty State

- projectが見つからない場合はErrorState相当。
- 関連データがない場合は空リスト相当。
