# `/lps/[lpId]/edit`

> **履歴UI資料:** このページ文書は初期UI監査時点の記録です。現在の画面・接続状態は [`../adflow-ai-current-state.md`](../adflow-ai-current-state.md) を参照してください。


## 目的

既存Landing Pageを編集するフォーム画面。更新時にLP versioningの文脈を持つ。

## 現在UIに表示される主な内容

- 既存LP情報が入った編集フォーム
- Form fields
  - name
  - URL
  - hero title/subtitle
  - CTA
  - offer
  - target audience
  - behavior/performance metrics
  - notes
- Save LP button

## 主なユーザー操作

- LP情報編集
- 保存
- 戻る

## Empty State

- lpIdが存在しない場合はErrorStateまたは読み込み失敗。
