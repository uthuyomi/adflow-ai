# `/pairs/new`

## 目的

登録済み広告とLPを組み合わせて分析対象ペアを作成する。

## 現在UIに表示される主な内容

- Form fields
  - project
  - pair name
  - twitter ad selection
  - landing page selection
  - status
- Create / Save button

## 主なユーザー操作

- 広告を選択
- LPを選択
- ペア名を入力
- 保存

## Empty State

- 広告またはLPがない場合、選択肢が空になり、先に登録が必要。
