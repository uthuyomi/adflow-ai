# `/lps/new`

## 目的

Landing Pageを手動登録するフォーム画面。

## 現在UIに表示される主な内容

- Form fields
  - project
  - name
  - URL
  - hero title
  - hero subtitle
  - primary CTA
  - secondary CTA
  - offer text
  - target audience
  - bounce rate
  - session duration
  - scroll depth
  - page speed
  - FCP / LCP
  - notes
- Save LP button

## 主なユーザー操作

- LP情報入力
- Save LP
- 一覧へ戻る

## Empty State

- projectがない場合、project選択が空になる可能性がある。
