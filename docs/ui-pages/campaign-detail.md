# `/campaigns/[campaignId]`

> **履歴UI資料:** このページ文書は初期UI監査時点の記録です。現在の画面・接続状態は [`../adflow-ai-current-state.md`](../adflow-ai-current-state.md) を参照してください。


## 目的

特定キャンペーンの広告、指標、改善候補を詳細表示する。

## 現在UIに表示される主な内容

- Campaign title
- Campaign metrics
  - impressions
  - clicks
  - spend
  - CTR
  - CPC
  - CVR
  - conversions
- 関連広告リスト
- 改善候補や分析サマリ

## 主なユーザー操作

- 関連広告の確認
- 一覧へ戻る
- Sidebar navigation

## Empty State

- campaignIdが存在しない場合はErrorState相当。
- 関連広告がない場合は空リスト。
