# `/pairs`

## 目的

広告とLPのペア一覧を表示し、ペア作成、詳細確認、編集、削除へ進める。

## 現在UIに表示される主な内容

- Page header
  - Ad LP Pairs
  - ペア管理説明
  - Button: `New pair`
- Pair list/table
  - Pair
  - Ad
  - LP
  - Status
  - Last analyzed
  - Actions

## 主なユーザー操作

- New pair
- Pair detailへ移動
- Edit
- Delete

## Empty State

```text
No pairs
Create a pair before running analysis.
```
