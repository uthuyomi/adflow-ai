# `/pairs/[pairId]/edit`

> **履歴UI資料:** このページ文書は初期UI監査時点の記録です。現在の画面・接続状態は [`../adflow-ai-current-state.md`](../adflow-ai-current-state.md) を参照してください。


## 目的

既存の広告LPペアを編集する。

## 現在UIに表示される主な内容

- 既存ペア情報が入った編集フォーム
- Pair name
- Ad selection
- LP selection
- Status
- Save button

## 主なユーザー操作

- ペア名変更
- 広告/LP紐づけ変更
- 保存

## Empty State

- pairIdが存在しない場合はErrorStateまたは読み込み失敗。
