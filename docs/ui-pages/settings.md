# `/settings`

## 目的

AI mode、接続設定、ワークスペース設定を確認・保存する。

## 現在UIに表示される主な内容

- Page header
  - Settings
  - Configure providers and workspace defaults.
- AI mode selector
  - OpenAI API only
  - AI OS router / AI Review Center router文脈
- Connection settings
  - Supabase project
  - X Ads connection status
  - Save settings
- Local validation message
  - `Settings validated locally.`

## 主なユーザー操作

- AI mode切り替え
- Supabase project入力
- X Ads connection status入力
- Save settings

## Empty State

初期値例:

```text
supabaseProject: adflow-prod
xAdsStatus: pending
```
