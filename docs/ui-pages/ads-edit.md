# `/ads/[adId]/edit`

## 目的

既存X広告を編集するフォーム画面。

## 現在UIに表示される主な内容

- 既存広告情報が入った編集フォーム
- Form fields
  - name
  - campaign/ad group
  - headline/body/CTA
  - destination URL
  - metrics
  - status
- Save button
- 戻る導線

## 主なユーザー操作

- 広告情報編集
- 保存
- 戻る

## Empty State

- adIdが存在しない場合はErrorStateまたは読み込み失敗。
