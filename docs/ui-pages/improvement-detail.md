# `/improvements/[improvementId]`

## 目的

改善提案の詳細、差分、レビュー警告、承認/却下/PR準備操作を表示する。

## 現在UIに表示される主な内容

- Improvement detail title
- Problems
- Suggestions
- Review warnings
- Diff
- Confirmation dialogs
  - Approve improvement?
  - Create pull request?
  - Reject improvement?
- Buttons
  - Approve
  - Create PR
  - Reject
  - Cancel

## 主なユーザー操作

- Approve
- Create PR
- Reject
- Cancel
- Confirm

## Empty State

```text
No selected improvement
```

## メッセージ

```text
Improvement approved for PR preparation.
PR creation request completed.
Improvement marked as rejected in this review session.
```
