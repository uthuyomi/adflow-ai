## 主なユーザー操作

- Sync
- Logout
- Sidebar navigation
- 検索入力
- 各カード/リストから詳細へ移動

## Empty State

- データがない場合、KPIは0または空状態。
- 各Demand Intelligenceカードは `No ... yet.` と表示。
- Getting Startedで未完了ステップが見える。
