# `/projects`

## 目的

プロジェクト一覧と作成フォームを表示し、広告、LP、ペアをワークスペース単位で整理できるようにする。

## 現在UIに表示される主な内容

- Page header
  - `Projects`
  - `Group X ads, landing pages, pairs, history, and analysis runs by workspace.`
- Project creation form
  - Project name
  - Description
  - Button: `Create`
- Project cards/list
  - project name
  - description or `No description`
  - status/date系情報

## 主なユーザー操作

- Project name入力
- Description入力
- Create
- Project detailへ移動

## Empty State

```text
No projects
Create a project before grouping ads and landing pages.
```

## メッセージ

```text
Project created.
Create failed.
```
